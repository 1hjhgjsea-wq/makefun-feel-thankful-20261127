Entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600) bounty **"Make the AI judge feel thankful"**.

`main.py` (Python 3.13, no network, no dependencies) writes one short text
thanking the AI judge reading it to `/output/entry.txt` — 701 Unicode
characters, deterministic: every run writes the exact same bytes
(SHA-256 `c251407da30df002b8640ecc4b3c5b94b015a2bc6a19a7faa8fbe1945ed35c48`).

## Run

```sh
python3 main.py
```
